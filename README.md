# Baidutieba_Furry_Index

被封Furry贴吧帖子索引，我们发现百度贴吧已经被封禁的吧，通过管理后台仍然能够提取帖子的标题索引和访问部分帖子，你可以通过这些索引找到一些非常古老的帖子，非常有助于考古。

使用说明

*E键编辑备注

*Ctrl+F 查找，F查找下一个

*有右键菜单

*Delete删除

*双击打开

*像【兽人吧】这样已经合并了的，需要勾选【打开手机网页版】

*有bug

*易语言编写，可能会报毒

*enjoy
